# Desktop Island v1.6 (Windows 10 / 11)

Нативное лёгкое приложение в стиле Dynamic Island для Windows (дизайн вдохновлён макетом Atoll), написанное на **C# + WPF (.NET 8)**.

## Что нового в v1.6
- **Свободное перетаскивание и Notch-режим:** островок можно перетащить в любую точку экрана (X/Y) без возврата назад, либо примагнитить к верхнему/левому/правому краю; по умолчанию прилипает сверху как Notch (с выбором отступа в настройках).
- **Обновлённая вкладка `Главная`:** 6 круглых кнопок быстрых действий (`QR-код`, `Пипетка`, `Чистый текст`, `Запись экрана`, `Команда`, `Перевод RU ⇄ EN`), спаренный блок **Музыка + Погода** с переключателем плееров (`Авто / Spotify / SoundCloud / YT Music`) и чистый macOS-док с индикатором запущенных программ, живым поиском по `+` и переключением `Док / Сетка`.
- **Музыкальная студия (`Музыка`):** крупная обложка альбома с динамическим свечением, бегущим эквалайзером, кликабельной полосой перемотки, выбором плеера и поэкранным/попроцессным микшером.
- **Пункт управления (`Система`):** быстрые тумблеры (`Wi-Fi`, `Bluetooth`, `Полёт`, `VPN`, `Чистый стол`, `Клип 30с`, `Запись`), живые спарклайн-графики CPU / GPU / RAM и сводка устройств.
- **Игровой режим:** круглый значок активной игры, цветной FPS (>60 зелёный / <45 красный), температура GPU (>85 красный) и визуальная полоса нагрузки + кнопка буста ОЗУ.
- **Тихий режим ожидания и автопроверка обновлений:** глаза появляются только при реальном простое, а островок проверяет новые релизы на GitHub раз в 90 минут.

## Обновление и передача друзьям
- **Если у друга уже установлен Desktop Island:** достаточно отправить ему [Update_DesktopIsland_Friend.bat](Update_DesktopIsland_Friend.bat) — скрипт сам скачает последний `DesktopIsland.zip` из GitHub Releases, сохранит `Config\` и перезапустит программу от администратора.
- **Для новой установки (включая офлайн без заранее установленного .NET 8):** отправьте целиком [DesktopIsland.zip](DesktopIsland.zip) — внутри лежат автономная сборка `App\DesktopIsland.exe`, `Install_DesktopIsland.bat`, `Update_DesktopIsland.bat` и `Uninstall_DesktopIsland.bat`.

## Расположение и структура
- `E:\Applications\DesktopIsland\App\DesktopIsland.exe` — собранное исполняемое приложение.
- `E:\Applications\DesktopIsland\Source\` — полный исходный код проекта (`DesktopIsland.csproj`, `MainWindow`, `Views`, `Services`, `Models`).
- `E:\Applications\DesktopIsland\Assets\` — иконка приложения (`Icons\app.ico`) и логотип (`Images\logo.png`).
- `E:\Applications\DesktopIsland\Config\settings.json` — сохранённые пользовательские настройки.
- `E:\Applications\DesktopIsland\Logs\` — ежедневный журнал ошибок и событий.

## Реализованные функции
1. **Дизайн и поведение капсулы:**
   - Скруглённая капсула в notch- или плавающем режиме, с боковым докингом (`Left` / `Right`), магнитным откликом на курсор и сохранением отдельной позиции островка под каждый процесс/игру.
   - Живые **круглые глаза** в режиме реального бездействия (смотрят прямо или отводят взгляд и моргают, скрывая лишние кнопки), мгновенно просыпаются при вводе с клавиатуры или движении мыши.
   - Компактный режим (время, погода, FPS, CPU/GPU/RAM, сеть, музыка с обложкой и эквалайзером) и плавное раскрытие при наведении мыши (либо закрепление кнопкой 📌).
2. **Быстрый запуск:** закрепление программ, добавление/удаление/сортировка, извлечение иконок, запуск в 1 клик.
3. **Системный и сетевой монитор:** загрузка CPU (`GetSystemTimes`), использованная/свободная RAM (`GlobalMemoryStatusEx`), GPU %, температура, FPS/Frame-time, скорость сети (↓/↑), нестабильность пинга и всплески скачивания.
4. **Монитор дисков и загрузки:** состояние дисков, топ процессов с завершением и кликабельные недавние загрузки (с открытием файла и папки).
5. **Пульт, музыка, буфер и утилиты:** мини-плеер (Spotify/SoundCloud/Auto), яркость DDC/CI, микшер приложений, привязка аудиоустройства к игре, **запись экрана в MP4 (выбор монитора)**, 30с игровой клип, «Стрим-щит», умный буфер обмена, полка перетаскивания, калькулятор/конвертер валют и QR-генератор.
6. **Безопасный модуль очистки:** анализ и удаление временных файлов `%TEMP%`, `C:\Windows\Temp`, кэша миниатюр, отчётов WER и Корзины.
7. **Автозапуск и трей:** значок в области уведомлений, запуск от администратора и полное завершение через меню или настройки.

## Сборка из исходников
```powershell
dotnet publish E:\Applications\DesktopIsland\Source\DesktopIsland.csproj -c Release -o E:\Applications\DesktopIsland\App --no-self-contained
```
